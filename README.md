# 거울 분해소

공식은 못 풀고 QR은 풀었다? — QR 분해를 손으로 체험하는 앱입니다. 두 열이 1억 분의 1만 다른 최소제곱 문제를 교과서 공식((AᵀA)⁻¹Aᵀb)과 QR로 직접 풀어 보는 첫 장면(브라우저가 실제 배정밀도로 계산), 벡터를 끌어 보는 그람 슈미트 Q·R 만들기(원고 예 Q = [[0.6, 0.8], [0.8, −0.6]], R = [[5, 2], [0, 1]]), 퀴즈 ①(길이 5), 길이를 지키는 Q, 단계별 후진 대입(b = (7, 6) → Qᵀb = (9, 2) → x = (1, 2))과 퀴즈 ②, 대각선 곱 행렬식, 1 + 10⁻ᵏ 실험, 힐베르트 행렬 직교화 대결(고전·수정 그람 슈미트·하우스홀더, 기기에서 직접 계산), 하우스홀더 거울, 기븐스 회전, 조건수와 AᵀA의 함정, QR 반복으로 고윳값 찾기까지 담았습니다. 선형대수 11 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① Q와 R: 첫 장면, 그람 슈미트로 Q·R 만들기, 퀴즈 ①, Q의 성질
- ② 풀기: 후진 대입, 퀴즈 ②, 행렬식
- ③ 거울·회전: 부동소수점, 힐베르트 직교화 대결, 하우스홀더, 기븐스
- ④ 조건수: 조건수와 AᵀA, QR 반복, 분해 삼총사, 코드, 세 줄 정리, 생각해 볼 질문

모든 계산은 이 앱이 브라우저에서 직접 수행하며(넘파이와 같은 IEEE 배정밀도), 힐베르트 행렬 조건수 표시값만 넘파이로 미리 계산해 넣었습니다.
