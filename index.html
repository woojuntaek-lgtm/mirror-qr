🎯 하나씩 돌려 지우기: 기븐스 회전

대부분이 0인 희소 행렬. 기븐스는 두 줄만 골라 돌려 원소 하나를 정확히 0으로 만듭니다. 이미 0인 곳은 건드리지 않습니다.

거울은 한 번에 많이, 회전은 정밀하게 하나씩. 둘 다 길이를 지키는 직교 변환이라 오차를 키우지 않습니다.

import numpy as np from scipy.linalg import solve_triangular A = np.array([[3., 2], [4, 1]]) Q, R = np.linalg.qr(A) # Q 첫 열 (-0.6, -0.8), R 첫 줄 (-5, -2) — 부호만 반대 Q.T @ Q # 단위 행렬 x = solve_triangular(R, Q.T @ np.array([7., 6])) # [1. 2.] A = np.array([[1, 1], [1e-8, 0], [0, 1e-8]]); b = A @ [1, 1] np.linalg.solve(A.T @ A, A.T @ b) # LinAlgError: Singular matrix Q, R = np.linalg.qr(A) np.linalg.solve(R, Q.T @ b) # [1. 1.] np.linalg.cond(A) # 약 1.414e8 np.linalg.lstsq(A, b, rcond=None)[0] # 더 안정적인 방법이 알아서

📌 세 줄 정리

  1. QR 분해는 행렬을 직교 행렬 Q와 위 삼각 행렬 R로 나누고, Q의 역행렬은 전치, R은 후진 대입으로 푼다.
  2. 컴퓨터 속 직교화는 뺄셈 오차가 쌓이니 하우스홀더 거울이나 기븐스 회전을 쓴다.
  3. AᵀA는 조건수를 제곱으로 키우니, 최소제곱은 역행렬 대신 분해로 푼다.
